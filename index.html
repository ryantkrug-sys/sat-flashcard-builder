SAT & PSAT Missed-Question Flashcard Builder

Choose SAT, PSAT 10, or PSAT 8/9, then select a practice test, section, and module. Select the questions you missed, choose your index-card size and how many questions to place on each page, then export your flashcards as a Microsoft Word document or PDF.

1. Choose the questions

Connecting to the question bank…

Choose one or more questions. The list updates when you change the test, section, or module.

2. Set up the flashcard pages

Word creates an editable document containing all selected images. PDF creates a ready-to-print file.

Question images are retrieved from the public sat-question-bank repository. This tool only reads the bank; it does not modify its files.
