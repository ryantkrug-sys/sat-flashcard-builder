SAT & PSAT Missed-Question Flashcard Builder

Choose SAT, PSAT 10, or PSAT 8/9, then select a practice test, section, and module. Select the questions you missed, choose your index-card size and how many questions to place on each page, then export your flashcards as a Microsoft Word document, Google Docs-compatible file, or PDF.

Connecting to the question bank…

Choose one or more questions. The list updates when you change the test, section, or module.

2. Set up the flashcard pages

Microsoft Word is the recommended option. Google Docs downloads a compatible document that you can upload to Google Drive and open with Google Docs. PDF creates a ready-to-print file.

Question images are retrieved from the public sat-question-bank repository. This tool only reads the bank; it does not modify its files.
